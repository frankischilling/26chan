## Review corrections

The GIF reader stops at its first trailer. Checking only the last input byte
allowed an additional trailer, appended `JUNK;`, or another complete GIF to be
ignored. A regression failed on the original implementation. The guest now
recovers the decoder's buffered reader and requires EOF after the consumed
trailer. All eight decoder tests pass. Native intake also tests both appended
data and concatenated GIF rejection before a healthy publication.

The filter controller previously aborted a pending pass on page suspension but
did not restart it when the browser restored the page. A regression reproduced
the missing pass without manually retrying. The controller now suspends its
observer and work, resumes with a new pass on persisted `pageshow`, and removes
its lifecycle listeners on final teardown. The old caller remains cancelled.

A separate updater regression showed that rejected feature processing left new
posts, changed thread flags and disabled forms in the document. Counts and state
events had already been published. New posts now remain provisional until the
callback succeeds. Failure removes them; cancellation removes them immediately
even when the callback has not returned. Tail metadata, form policy, counts and
state events commit only after successful integration. The rejected, cancelled
and successful cases passed against the built page module and real parser.

The exact browser CSP expectation now includes the fixed display, thread-control
and statistics assets. The healthy alternate-script and inline-script denial
checks remain intact. The archive fixture launcher now honors `CARGO_TARGET_DIR`
and reports launch errors directly. The new expansion browser test was corrected
to use the HTML index's existing three-reply tail rather than the JSON preview's
five replies; the passing test verifies that all five omitted replies are added.
The watcher traffic fixture disables the independent statistics feature before
thread navigation so its exact request assertions continue to measure watcher
behavior. Dedicated tests retain default-on statistics and its transport checks.

An earlier Linux run could not launch Node. Node 24.14.0 was installed from the
official archive after its published SHA-256 matched, with separate Linux npm
artifacts and the pinned Chromium build. No environment failure was treated as
a passing application test.
