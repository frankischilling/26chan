# Untrusted replay wire controls

These local candidate-wire fixtures are not approved or playable media. Both
Rust codecs use the same frozen bytes, with no dependency between codecs across
the guest/privileged-host boundary. The guest tests parse the pinned TGKR input and
compare its complete encoding to these bytes. The host independently decodes
the bytes and compares source values. Separate literal byte controls test
each implementation without relying only on encoder/decoder agreement.

`generate.py` is an independent, test-only Python `struct`/raw-DEFLATE
transcription. It imports neither Rust codec, checks hard-coded input SHA-256
pins, and preserves each source field's bits. Run from the repository root:

```sh
python3 tests/media/fixtures/replay-wire/generate.py
PYTHONOPTIMIZE=1 python3 tests/media/fixtures/replay-wire/generate.py
PYTHONOPTIMIZE=2 python3 tests/media/fixtures/replay-wire/generate.py
```

Use `--record` only to replace fixtures deliberately. Explicit errors enforce
the CLI, source hashes, bounded inflation, structural checks and frozen-output
equality, even under Python optimization. All source inputs are verified before
record mode can write any output. Normal Rust tests need neither Python nor the
original JavaScript checkout.

`npm run test:replay-foundation` includes this verification and bounded
temporary-copy controls under `PYTHONOPTIMIZE=0`, `1` and `2`. Those controls
reject source-pin changes (including same-length edits), frozen-output drift,
malformed CLI and malformed framing, and verify intentional record-mode
replacement. They do not mutate production source or checked-in fixture bytes.
The existing Linux and Windows drawing-core CI paths invoke the package script.

## Candidate wire version 1, profile 1

The stable magic is `IBRPLY01`. All multibyte values and float32 bit patterns are
big-endian. There is a 64-byte header, exactly eight sorted 24-byte tool slots,
and 16 bytes per event: precisely `256 + 16N`, for `2 <= N <= 16384`, at most
262,400 bytes. The profile ID identifies the representation, not approval.

Header offsets: magic 0, u16 version 8, u16 header size 10, u16 candidate profile
12, zero u16 flags 14, u32 total bytes 16, u32 event count 20, u16 width/height
24/26, RGB background/initial color 28/31, u8 initial tool 34, zero byte 35,
u32 start/end epoch seconds 36/40, source version bytes `[0,9,4,1]` 44, sixteen
zero bytes 48. Dimensions are 1..1024; initial tool is 1..8.

Tool offsets: u8 ID/size/flags 0/1/2, i8 tip 3, f32 alpha/step/flow 4/8/12,
eight zero bytes 16. Slots are IDs 1 through 8, in that order. Flags bits 0..3
are size dynamics, alpha dynamics, `usePreserveAlpha` (capability, not enabled
state), and flow dynamics. Upper bits must be zero.

Event offsets: u8 source tag 0, three zero bytes 1, u32 timestamp 4, eight-byte
payload 8. Used payload bytes are left aligned; every unused byte must be zero.

- Tags 1/2: i16 x, i16 y, u16 pressure (six bytes)
- Tags 7/8: i16 x, i16 y (four bytes), preserving no-pressure distinction
- Tag 6: RGB (three bytes)
- Tags 12/18/27: finite f32 (four bytes)
- Tag 10: tool ID 1..8 (one byte)
- Tags 13/14/16/17: canonical boolean 0/1 (one byte)
- Tags 11/15/22/24/25/26: source u8 (one byte)
- Tags 0/3/4/5/20/21/23/254/255: empty payload
- Other tags are rejected. Prelude 0 occurs only first; conclusion 255 only last.

Tool and event floats must be finite. Negative zero and finite out-of-semantic-
range values remain bit-for-bit unchanged. Tool order is canonicalized; source
inflated-byte length is structurally checked by the encoder but not carried.
All source event order, coordinates, timestamps, byte-sized values and metadata
are preserved without range normalization or inferred state changes.

This boundary does not validate tool dynamics, brush cost, layer IDs/history,
stroke ordering, chronology, or provenance/PNG correspondence. No replay is
approved, stored, served, rendered or sent through image dispatch. The host
decoder accepts a byte slice only; any future acquisition layer must enforce
packet byte limits and a job deadline before handing it the slice. Source
decompression stays in the guest. Any authoritative type or production integration
requires independent work on semantics, cost, and provenance.
